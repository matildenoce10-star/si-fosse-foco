# S'i' fosse foco

Presentazione interattiva di **Matilde Dellanoce**, Liceo Linguistico Giuseppe Parini.

Racconta come Fabrizio De André ha messo in musica il sonetto *S'i' fosse foco* di Cecco Angiolieri (album *Volume III*, 1968): i due autori, la struttura del sonetto e della canzone, il testo con la parafrasi, gli strumenti e un laboratorio musicale sul giro di accordi Am – F – E7 – Am.

## Come aprirla

- **Online:** tramite GitHub Pages.
- **In locale:** con Node.js installato, `node server.js` e poi http://localhost:5173

Navigazione: frecce ↑ ↓ oppure rotellina del mouse, tasto F per lo schermo intero.

## Note

- Il testo del sonetto (XIII secolo) è di pubblico dominio.
- La melodia del laboratorio musicale è originale e generata dal browser con la Web Audio API.
- Le immagini provengono da Wikimedia Commons (pubblico dominio o CC0).
